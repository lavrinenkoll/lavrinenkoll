## 🛠️ Key Projects

### [📊️ **Vacancy Analytics System: Parsing, Cleaning, and Visualization of Job Data**](https://github.com/lavrinenkoll/JobVacancyAnalyticsAI)
This project automates the collection, cleaning, and analysis of job postings from DOU and LinkedIn, focusing on job title, qualification level, location, company, candidate requirements, and employer offers. It provides structured and analytically processed labor market data with advanced visualizations.
Key features include web scraping with Selenium and BeautifulSoup, data cleaning and enrichment using GROQ API (level extraction, translation, keywords), word cloud visualizations, platform comparison charts, and OLAP 3D graphs.
![Interface](https://github.com/lavrinenkoll/lavrinenkoll/blob/main/imgs/7.png)

### [📦 **Image Processing and Cataloging System**](https://github.com/lavrinenkoll/ImageScraper)
A comprehensive system for scraping, normalizing, and cataloging images from online sources. This project features advanced image processing using machine learning models like ResNet50 and MobileNetV2, with a user-friendly interface for seamless data organization.
![Interface](https://github.com/lavrinenkoll/lavrinenkoll/blob/main/imgs/1.png)

### [🌦️ **Weather AI Bot**](https://github.com/lavrinenkoll/WeatherAIBot)
An interactive bot for providing weather forecasts and outfit suggestions based on current conditions. Leveraging APIs like Firebase and cloud platforms, the bot includes real-time data visualization and user personalization features.
